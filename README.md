# Reboot the Earth — Cold-Chain Food AI

A hackathon-ready React dashboard for dynamic cold-chain management and food-loss reduction.

## Run locally

```bash
npm install
npm run dev
```

Then open:

```text
http://localhost:5173
```

## Notes

- Built as a single-page frontend demo.
- Uses simulated/mock data only.
- No real sensors, GPS, traffic APIs, or backend.
- Includes dynamic shelf-life logic, financial sufficiency checks, and anomaly rerouting logic.
